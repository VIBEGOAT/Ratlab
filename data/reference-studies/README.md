# Reference-study evidence packages

These packages are the boundary between published observations and VAST model output.
A drug name or citation is not enough to mark a case as validated.

A package may enter `ready` status only when it includes:

1. the primary source and a stable dataset identifier;
2. species, strain, sex, age or weight, group size and control definition;
3. formulation, route, dose units, dose groups, frequency and duration;
4. sampling times and endpoint units;
5. observed group summaries or individual-level observations with variability;
6. a recorded transcription check by a second reviewer;
7. an explicit statement of whether the source reported a NOAEL/LOAEL;
8. licence or reuse terms for every redistributed table.

VAST uses three evidence labels:

- `observed`: transcribed from the cited source without model interpolation;
- `fitted`: generated by a model fitted to the observed values;
- `predicted`: generated for a condition not directly observed in that source.

Missing values stay `null`. They must never be replaced with plausible-looking estimates.
