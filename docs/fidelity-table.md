# Model fidelity table

Generated by `npm run gen:docs` from the fidelity registry (simulator version 0.1.0-phase-a). Do not edit by hand.

> Research and education tool. Not validated for regulatory or safety decisions.

Meaning of the labels:

- **MECHANISTIC**: standard equations or algorithms that can be checked by tests.
- **SEMI-QUANTITATIVE**: mechanism-shaped, but parameters are assumed or tuned, not fitted to data.
- **ILLUSTRATIVE**: shows how the pieces connect. No predictive claim.

## MECHANISTIC (5)

| Subsystem | Why this label |
|---|---|
| Random number generation | Deterministic seeded generator; behaviour is fully testable. |
| PBPK solver and mass balance | Flow-limited whole-body model propagated exactly with a matrix exponential; mass conservation and agreement with an adaptive ODE solver are unit-tested. Compound parameters are fictional archetypes. |
| PD models (Emax, effect compartment, indirect response, transit, tolerance) | Textbook model forms checked against their analytic steady states. Parameters are archetype placeholders. |
| Untreated twin | Same seed, physiology and disease parameters with zero dose, so differences are due to treatment alone. The model it runs on is SEMI-QUANTITATIVE. |
| Statistics (ANOVA, Dunnett, Kruskal-Wallis, Dunn, trend, Fisher, Kaplan-Meier, log-rank) | Implemented from the published formulas and checked against hand-computed examples and by simulation (Dunnett familywise error rate). |

## SEMI-QUANTITATIVE (7)

| Subsystem | Why this label |
|---|---|
| Rat physiology parameters | Taken from the literature; several values still UNVERIFIED and not matched to a specific strain or vendor. |
| Organ damage D(t) | Mechanism-shaped equations with archetype parameters that are not fitted to data. |
| Clinical pathology mapping from damage | Reference ranges come from the literature; the damage-to-marker mapping is assumed. |
| Tumor and diabetes overlays | Gompertz tumor growth with log-cell-kill and resistance, and glucose, HbA1c-like and complication states. Standard model forms with uncalibrated parameters. Other disease modules are not implemented. |
| Humane endpoint logic | Criteria follow the concepts in OECD GD 19. Threshold values are placeholders and must be replaced with institutional policy. |
| NOAEL, LOAEL and MTD determination | Rule-based adversity call (significance, trend, relevance, effect size, corroboration). Thresholds are design values for a toxicologist to set. |
| Monte Carlo forecast and sensitivity screening | Correct sampling and Morris screening, but variability parameters are placeholders so probabilities are not calibrated. |
